How to Test

  1. Go to the admin interface: /app/cart-drawer/free-shipping-bar
  2. Select "Item Count" mode from the dropdown
  3. Set threshold count (e.g., 5 items)
  4. Update the message to use "{remaining} more items"
  5. Save the configuration
  6. Test with different cart item counts to see the progress bar update

# Environment Variables Guide

This document describes all environment variables used in the Upsellity AI application.

## Required Environment Variables

### Shopify Configuration

#### `SHOPIFY_API_KEY`
- **Description**: Your Shopify app's Client ID
- **Where to find**: Shopify Partner Dashboard → Apps → [Your App] → Client credentials
- **Example**: `d64798b1d19d1bbad676d9411146f2d3`
- **Required**: Yes

#### `SHOPIFY_API_SECRET`
- **Description**: Your Shopify app's Client Secret
- **Where to find**: Shopify Partner Dashboard → Apps → [Your App] → Client credentials
- **Example**: `shpss_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`
- **Required**: Yes
- **Security**: Never commit this to version control

#### `SHOPIFY_APP_URL`
- **Description**: The public URL where your app is hosted
- **Development**: Auto-generated by Shopify CLI (e.g., `https://xxx.trycloudflare.com`)
- **Production**: `https://app.upsellity.com`
- **Required**: Yes
- **Note**: Must use HTTPS

#### `SCOPES`
- **Description**: Comma-separated list of Shopify API scopes your app requires
- **Default**: `write_products,read_products,read_product_listings,write_checkouts,read_checkouts`
- **Required**: Yes
- **Note**: Must match scopes in `shopify.app.toml`

### Database Configuration

#### `DATABASE_URL`
- **Description**: Connection string for your database
- **Development**: `file:./prisma/dev.sqlite`
- **Production**: PostgreSQL or MySQL connection string
- **Required**: Yes
- **Examples**:
  ```
  # PostgreSQL
  postgresql://user:password@localhost:5432/upsellity
  
  # MySQL
  mysql://user:password@localhost:3306/upsellity
  
  # SQLite (dev only)
  file:./prisma/dev.sqlite
  ```

### Extension Configuration

#### `SHOPIFY_CART_UPSELL_EXTENSION_ID`
- **Description**: ID of your deployed cart upsell extension
- **Where to find**: After running `shopify app deploy`, or in Partner Dashboard
- **Example**: `27de7a0f-16d2-26c3-ac46-904a094e21ffb93d65db`
- **Required**: Yes (for extension functionality)

### Node Configuration

#### `NODE_ENV`
- **Description**: Application environment
- **Values**: `development` | `production` | `test`
- **Default**: `development`
- **Required**: Recommended
- **Note**: Automatically set to `production` in Dockerfile and GitHub Actions

#### `PORT`
- **Description**: Port on which the application listens
- **Default**: `3000`
- **Required**: No
- **Note**: Should match Docker EXPOSE and ECS port mapping

## Optional Environment Variables

#### `SHOP_CUSTOM_DOMAIN`
- **Description**: Custom domain for shops (if using custom shop domains)
- **Example**: `myshop.example.com`
- **Required**: No
- **Note**: Only needed for apps with custom shop domains

#### `HOST`
- **Description**: Legacy host variable (being phased out by Shopify CLI)
- **Required**: No
- **Note**: Automatically converted to `SHOPIFY_APP_URL` in `vite.config.ts`

#### `FRONTEND_PORT`
- **Description**: Port for HMR (Hot Module Replacement) in development
- **Default**: `64999` (localhost) or `8002` (remote)
- **Required**: No

## Environment Setup by Environment

### Development (Local)

Create a `.env` file in the project root:

```bash
# Shopify Configuration
SHOPIFY_API_KEY=your_dev_api_key
SHOPIFY_API_SECRET=your_dev_api_secret
SHOPIFY_APP_URL=https://your-tunnel.trycloudflare.com
SCOPES=write_products,read_products,read_product_listings,write_checkouts,read_checkouts

# Database
DATABASE_URL=file:./prisma/dev.sqlite

# Extensions
SHOPIFY_CART_UPSELL_EXTENSION_ID=your_extension_id

# Node
NODE_ENV=development
```

**Start development server:**
```bash
npm run dev
# This uses shopify app dev which handles tunneling and env vars
```

### Production (ECS)

Environment variables are set in two places:

1. **GitHub Secrets** (sensitive values):
   - `AWS_ACCESS_KEY_ID`
   - `AWS_SECRET_ACCESS_KEY`
   - `DATABASE_URL`
   - `SHOPIFY_API_KEY`
   - `SHOPIFY_API_SECRET`
   - `SHOPIFY_CART_UPSELL_EXTENSION_ID`

2. **GitHub Actions Workflow** (non-sensitive values):
   - `NODE_ENV=production`
   - `SHOPIFY_APP_URL=https://app.upsellity.com`
   - `SCOPES=write_products,read_products,read_product_listings,write_checkouts,read_checkouts`

These are injected into the ECS task definition during deployment.

### Docker (Local Testing)

Create a `.env.docker` file:

```bash
NODE_ENV=production
DATABASE_URL=postgresql://user:password@host.docker.internal:5432/upsellity
SHOPIFY_API_KEY=your_api_key
SHOPIFY_API_SECRET=your_api_secret
SHOPIFY_APP_URL=http://localhost:3000
SCOPES=write_products,read_products,read_product_listings,write_checkouts,read_checkouts
SHOPIFY_CART_UPSELL_EXTENSION_ID=your_extension_id
```

**Run with Docker:**
```bash
docker build -t upsellity-app .
docker run --env-file .env.docker -p 3000:3000 upsellity-app
```

## Security Best Practices

### ✅ DO:
- Use environment variables for all secrets and configuration
- Store production secrets in GitHub Secrets or AWS Secrets Manager
- Use different API keys for development and production
- Rotate secrets regularly
- Use `.gitignore` to exclude `.env` files

### ❌ DON'T:
- Commit `.env` files to version control
- Share secrets via email or chat
- Use production credentials in development
- Hardcode secrets in source code
- Log environment variables in production

## Verifying Environment Variables

### In Node.js Application

```javascript
// Check if required env vars are set
const requiredEnvVars = [
  'SHOPIFY_API_KEY',
  'SHOPIFY_API_SECRET',
  'SHOPIFY_APP_URL',
  'DATABASE_URL',
  'SCOPES'
];

requiredEnvVars.forEach(envVar => {
  if (!process.env[envVar]) {
    console.error(`Missing required environment variable: ${envVar}`);
    process.exit(1);
  }
});
```

### In Docker Container

```bash
# Connect to running container
docker exec -it <container_id> sh

# Check environment variables
env | grep SHOPIFY
env | grep DATABASE
```

### In ECS Task

```bash
# Using AWS CLI
aws ecs describe-tasks \
  --cluster upsellity \
  --tasks <task_id> \
  --query 'tasks[0].containers[0].environment'

# Or use ECS Exec
aws ecs execute-command \
  --cluster upsellity \
  --task <task_id> \
  --container app \
  --interactive \
  --command "/bin/sh"

# Inside container
env | grep SHOPIFY
```

## Troubleshooting

### Error: "SHOPIFY_APP_URL is not defined"
- **Cause**: Missing or incorrect `SHOPIFY_APP_URL` environment variable
- **Solution**: Ensure it's set in your environment or GitHub Secrets
- **Development**: Should be auto-set by `shopify app dev`
- **Production**: Must be explicitly set to `https://app.upsellity.com`

### Error: "Invalid API credentials"
- **Cause**: Incorrect `SHOPIFY_API_KEY` or `SHOPIFY_API_SECRET`
- **Solution**: Verify credentials in Shopify Partner Dashboard
- **Note**: Make sure you're using the correct credentials for your environment

### Error: "Database connection failed"
- **Cause**: Invalid `DATABASE_URL`
- **Solution**: 
  - Verify connection string format
  - Check database is running and accessible
  - Verify security groups (for AWS RDS)
  - Test connection manually

### Error: "Scope mismatch"
- **Cause**: `SCOPES` in environment doesn't match `shopify.app.toml`
- **Solution**: Ensure both use the same comma-separated list of scopes
- **Note**: After changing scopes, users must reinstall the app

## Migration from Development to Production

1. **Update App URL**:
   ```bash
   # Development
   SHOPIFY_APP_URL=https://xxx.trycloudflare.com
   
   # Production
   SHOPIFY_APP_URL=https://app.upsellity.com
   ```

2. **Update Database**:
   ```bash
   # Development
   DATABASE_URL=file:./prisma/dev.sqlite
   
   # Production
   DATABASE_URL=postgresql://user:pass@host:5432/upsellity
   ```

3. **Update Shopify Config**:
   - Use `shopify.app.prod.toml` for production
   - Update URLs in Shopify Partner Dashboard
   - Redeploy app: `shopify app deploy`

4. **Set GitHub Secrets**:
   - Add all required secrets in repository settings
   - Verify in GitHub Actions workflow

5. **Deploy**:
   ```bash
   git push origin main
   # GitHub Actions will handle the rest
   ```
